# Portofolio — Zefa Anugrah Budhilaksana

Website statis (HTML/CSS/JS), tanpa build.

## Deploy ke Vercel
1. Buat repo baru di GitHub (mis. `portfolio-zefa`), upload semua isi folder ini.
2. vercel.com -> Add New -> Project -> pilih repo -> Deploy (Framework: Other).
3. Tiap push ke repo, website ikut update otomatis.

## Edit konten
- Teks & link: `index.html`
- Gambar: `assets/img/` (ganti file dengan nama sama)
